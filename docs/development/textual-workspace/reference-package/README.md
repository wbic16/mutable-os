# Textual Workspace — Astra investigation package

Start with `TEXTUAL_WORKSPACE_FEATURE_BRIEF.md`. This package requests **investigation and planning only**.

- `TEXTUAL_WORKSPACE_FEATURE_BRIEF.md`: product contract, architecture questions, parity, tests and required report.
- `textual-palette.css`: semantic Borland-style colours plus muted Paper preset.
- `textual-grid.css`: illustrative grid-aligned CSS, subgrid, media and hard shadows.
- `layouts/textual-layouts.ts`: typed, pure responsive cell-geometry examples.
- `layouts/WIREFRAMES.md`: Flint, Scry, Gloss/References and Cardex layouts.
- `reference/`: existing Flint screenshots and latest TUI concept; **visual references, not layout specifications**.

CSS and TypeScript are templates, not prequalified production code. Astra must inspect the repository before recommending reuse or implementation.
